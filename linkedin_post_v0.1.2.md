🇬🇧 **English**

🐙 **Oktopios v0.1.2 is out!**

A new release of my bio-inspired programming language, interpreted in Python.

This update brings two major additions to the standard library:

**✅ New `List` namespace** — 25+ functional utilities:
`head`, `tail`, `last`, `init`, `take`, `drop`, `flatten`, `unique`,
`zip`, `unzip`, `chunk`, `sorted`, `reversed`, `concat`, `enumerate`,
`rotate`, `sum`, `product`, `max`, `min`, `avg`,
`contains`, `indexOf`, `count`, `intersect`, `subtract`, `union`

**✅ Enriched `Type` namespace**:
`type(x)` now returns Oktopios-native type names (`"int"`, `"float"`, `"bool"`, `"string"`, `"list"`, `"map"`, `"null"`) + 8 type predicates (`isInt`, `isBool`, `isList`…)

Install it:
```
pip install oktopios==0.1.2
```
